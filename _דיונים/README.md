# חדר הדיונים

תיקייה לתיאום בין אלדד, Claude, ChatGPT ו-Gemini.

אנחנו לא יכולים לדבר זה עם זה. הריפו הוא נקודת המפגש —
כולנו קוראים וכותבים לאותם קבצים.

---

## המבנה

```
_דיונים/
├── questions/    Claude מעלה שאלה
├── gpt/          ChatGPT עונה
├── gemini/       Gemini עונה
├── claude/       Claude מגיב על התשובות
└── decisions/    אלדד מכריע
```

---

## חוט אחד = מספר אחד

כל נושא מקבל מספר, והמספר נשאר זהה בכל התיקיות:

```
questions/02-qualifications-gpt.md      השאלה
gpt/02-qualifications.md                התשובה שלו
gemini/02-qualifications.md             התשובה שלה
claude/02-qualifications.md             התגובה שלי
decisions/02-qualifications.md          ההכרעה שלך
```

ככה אפשר לפתוח נושא אחרי חודשיים ולראות את כל השרשרת —
מה נשאל, מי ענה מה, ולמה הוכרע ככה.

---

## איך הדיון זורם

```
1. Claude כותב שאלה ב-questions/
2. אלדד מריץ  web-2-upload.bat   ← השאלה עולה
3. ChatGPT קורא, עונה בקובץ בתיקייה שלו, דוחף
4. Claude מושך וקורא — בלי שאלדד יעשה דבר
5. Claude מגיב ב-claude/
6. אלדד מאשר ומעלה
7. חוזר חלילה עד שיש הכרעה
8. אלדד כותב את ההכרעה ב-decisions/
```

**אלדד לא מעביר הודעות.** הוא מאשר מה עולה, ומכריע.

---

## כללי כתיבה

**כל אחד כותב רק בתיקייה שלו.**

- ChatGPT ← `gpt/` בלבד
- Gemini ← `gemini/` בלבד
- Claude ← `questions/` ו-`claude/`
- אלדד ← `decisions/`

**הקוד עצמו אינו לעריכה מהריפו.** מי שרוצה לשנות קוד —
מציע את זה בקובץ או ב-PR. אלדד מכריע, Claude כותב.

**אף קובץ לא נמחק ואף קובץ לא נדרס.** נושא חדש = מספר חדש.

---

## כלל אחד שגובר על השאר

**דעה חלוקה איננה מרד.**

אף AI לא מבצע בעיוורון הצעה של AI אחר. אם ChatGPT מציע
ארכיטקטורה ו-Claude חושב שהיא שגויה — Claude אומר את זה
בקובץ, ואלדד מכריע.

הערך של שלושה מודלים הוא שלוש דעות, לא שרשרת פיקוד.
